Send from the Share Sheet

One-time setup with Apple's Shortcuts app. Afterwards, Orbit appears in the Share Sheet of Photos, Files and other apps, and videos are sent in original quality.

  1. Open Shortcuts → +, name it Orbit. Tap ⓘ → turn on Show in Share Sheet; receive Images, Media, Files.
  2. Add Scan QR or Barcode.
  3. Add Repeat with Each item in Shortcut Input.
  4. Inside the repeat add Get Contents of URL, URL = QR/Barcode (the scan result). Method POST, Request Body Form, field file of type File = Repeat Item.

Then in Photos or Files: Share → Orbit → scan the code on the PC or TV → accept there. The QR link works for uploads as-is. Prefer a fixed device? Use this link instead of scanning:
