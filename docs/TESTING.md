# Тестирование

## Автотесты (Windows, протокол целиком)

```bash
cd windows
dotnet test Orbit.Core.Tests
```
44 теста на реальном Kestrel (loopback): ключ сопряжения, отдача страницы, несколько файлов с проверкой SHA-256, запрет перезаписи (`photo (1).jpg`), path traversal, короткое тело → докачка по `offset`, неверный offset → 409, **обрыв соединения посреди файла → докачка**, приём выключен → 503, подтверждение/отказ, пауза/продолжение, отмена с удалением частичного файла, multipart от Shortcuts (+ объединение запросов в одну передачу), «данных больше, чем заявлено», санитайзер имён, фильтр LAN-адресов.

## Ручной CLI-отправитель

```bash
node tools/orbit-send.mjs --to <IP>:47717 --key <КОД> файл1 файл2 …
node tools/orbit-send.mjs --to <IP>:47717 --key <КОД> --drop-at 104857600 big.mov   # обрыв на 100 МБ + докачка
node tools/orbit-send.mjs --to <IP>:47717 --key <КОД> --shortcut photo.heic          # как iOS Shortcut
```
Печатает SHA-256 отправленных файлов. Сверка на ПК: `Get-FileHash`, на ТВ: `adb shell sha256sum /sdcard/Download/Orbit/<файл>`. Код сопряжения на ТВ виден в Settings.

## Чек-лист ручной проверки

1. **Обнаружение/сопряжение**: QR сканируется камерой iPhone → открывается страница с именем устройства; «New code» → старая ссылка получает «Pairing code expired».
2. **Приём выключен** → страница показывает «Receiving is turned off», радар серый.
3. **Подтверждение**: Accept/Decline; без ответа 90 с → «Request timed out».
4. **Несколько файлов** из «Файлов» и из Фото; прогресс, скорость, ETA на iPhone и приёмнике.
5. **Прерывание**: выключить Wi-Fi на iPhone на 5 с во время большого файла → включить → страница сама продолжает (до 6 попыток).
6. **Пауза/отмена на приёмнике**: отмена удаляет частичный файл; страница показывает «Transfer canceled».
7. **Хранилище Windows**: сменить папку на защищённую (например, `C:\Windows`) → сообщение «Can't save to that folder».
8. **Хранилище ТВ**: «Sort by type» → фото в `Pictures/Orbit`, видео в `Movies/Orbit`; удаление удержанием в Received.
9. **Пульт**: всё достижимо стрелками/OK/Back, фокус всегда виден.
10. **Брандмауэр Windows**: при отказе в доступе iPhone не подключится → «iPhone can't connect?» добавляет правило для частных сетей.
