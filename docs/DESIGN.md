# Дизайн-система Orbit

Единый визуальный язык для Windows, Android TV и страницы на iPhone.

## Идея
«Орбита»: устройство в центре, три кольца расходятся наружу — сигнал «меня видно». Кольца анимируются только когда приём реально возможен (приём включён + есть сеть), иначе ядро серое — состояние читается без текста. Это не копия радара AirDrop: отдельный знак (ядро + спутник) и градиент индиго → циан.

Типографика: Windows — Segoe UI Variable (Display для заголовков); iPhone — SF Pro (system-ui); TV — системный шрифт, крупнее (заголовок устройства 34 sp, тело 16 sp — читаемо с 3 м). На Windows нейтральные цвета берутся из ресурсов Fluent-темы (`TextFillColorPrimaryBrush`, `CardBackgroundFillColorDefaultBrush` …), поэтому светлая/тёмная тема переключаются вместе с системой.

## Экраны

**Windows (одно окно + трей)**
- Левая панель: знак, радар, имя ПК (переименование по карандашу), статус-пилюля, переключатели «Приём», «Спрашивать перед приёмом», папка сохранения (Изменить / Открыть).
- Правая: карточка «Send from your iPhone» — QR, 3 шага, адрес + копирование, «Add to the iPhone Share Sheet» (гайд), «iPhone can't connect?» (правило брандмауэра), код сопряжения + «New code».
- «Activity»: карточки передач (иконка типа, файл/кол-во, прогресс, скорость, ETA, Pause/Resume/Cancel/Show), пустое состояние.
- Оверлеи: онбординг (1-й запуск), запрос на приём (Accept по умолчанию, обратный отсчёт), гайд Shortcuts. Закрытие окна → работа в трее.

**Android TV (10-футовый интерфейс, только пульт)**
- Главный: слева радар + имя + статус + кнопки (Received / Settings / Turn off), справа крупный QR и шаги; ниже — активная передача (сжимает QR) или «Recently received».
- Received: сетка 4 колонки с превью (Coil, кадры видео), OK — открыть (фото во встроенном просмотрщике ←/→, остальное — внешним приложением), удержание — удалить.
- Settings: список с крупными строками; имя через экранную клавиатуру; «Save to» — Downloads / Sort by type / Choose a folder (неактивно с объяснением, если на ТВ нет пикера).
- Диалог приёма: фокус сразу на Accept.
- Фокус: увеличение 1.06 + белая обводка — видно с дивана.

**iPhone (страница)**
- Радар + «Sending to <device>», статус. Кнопки «Photos & Videos» / «Files». Список с превью → Send → ожидание подтверждения → прогресс (%, скорость, ETA, счётчик) → «Sent» с галочкой. Удержание экрана (Wake Lock) во время передачи. Секция «Send from the Share Sheet» с копируемым URL.

## Потоки
1. Первый запуск → онбординг → QR на экране.
2. iPhone: Камера → QR → страница (можно «На экран Домой») → выбрать → Send → (ПК/ТВ: Accept) → прогресс → готово, уведомление на приёмнике.
3. Share Sheet: Фото → Поделиться → «Send to Orbit» → (Accept) → файл в папке.
